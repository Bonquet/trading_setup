# market_conditions/

One file per condition type. Track how trades perform in each, which strategy works best, what signals become unreliable, whether trades should be avoided entirely.

Condition types:
- `strong_trend.md`
- `weak_trend.md`
- `sideways_chop.md`
- `breakout_environment.md`
- `pullback_continuation.md`
- `high_volatility.md`
- `low_volatility.md`
- `news_driven.md`
- `session_london.md` / `session_ny.md` / `session_asia.md`
