# losses/

Losing trades. For each loss, capture:
- Why the trade failed
- Normal probability loss vs poor execution?
- Were market conditions actually poor?
- Did the setup violate any rule?
- Was the stop too tight or too wide?
- Was the trade taken too early?
- Was confirmation weak or incomplete?
- Was higher-timeframe ignored?
- Emotional / impulsive behavior?

Use this folder to **reduce repeated mistakes** and prevent low-quality setups from being taken again.

Filename: `YYYY-MM-DD_<instrument>_<strategy>.md`
