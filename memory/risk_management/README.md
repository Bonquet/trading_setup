# risk_management/

Lessons on stop placement, target selection, position sizing. One file per topic:
- `stop_placement.md` — tight vs wide, structure-based examples
- `target_selection.md` — 2R vs pivot vs trailing vs swing
- `position_sizing.md` — sizing against stop distance and account
- `trailing_exits.md` — when trailing beat fixed TP and when it didn't
- `trade_management.md` — BE moves, partials, when to exit early

Track whether rules were followed (risk inside 0.5–1% per trade, stops tied to structure, 2R targets realistic).
