# market_profiles/

One file per instrument. Track:
- How cleanly it trends
- Does it respect retracement zones?
- Does it react well to EMA entries?
- Volatility level
- False-breakout frequency
- Best timeframe
- Which strategy performs better on it

Filename: `<instrument>.md` — e.g. `XAUUSD.md`, `EURUSD.md`.

Seed notes for XAUUSD:
- Trends aggressively; respects 50–61.8% fibs well during London/NY.
- Fits Pullback strategy naturally.
- News-sensitive: US CPI, FOMC, NFP cause large fake moves — skip.
- Best TFs: H4 for setup, H1 for entry.
